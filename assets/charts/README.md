# グラフ素材

`bar.svg`（項目比較）、`line.svg`（月別推移）、`donut.svg`（構成比）は架空データの作例です。3種類とも480×360のSVGで、軸・値・凡例を画像内に含みます。スライドにそのまま挿入できます。外部通信や実行スクリプトは含みません。

`data.csv` は数値の控えです。CSVとSVGを自動同期する処理はありません。数値を変更する場合は、普段使う作図ツールから画像を書き出すか、AI Agentに次のように依頼してください。

> このCSVをもとに、Aizomeに合う棒グラフのSVGをassets/chartsへ作ってください。ai/colors.jsonの藍を使い、0始まりの軸・単位・値・項目名を入れ、図の外周に余白を確保してください。数値と棒の長さを照合し、figureで挿入して表示確認してください。

## SVGを制作・更新するAI Agentへ

- 元データを別ファイルに残し、作例か実データか、単位・期間・出典を明記する。
- 配色の原本は `ai/colors.json`。主系列は `palettes.ai.accent`、補助系列は `kohaku.accent`・`murasaki.accent`。背景と文字も `neutral` の色を使う。SVG画像にはスライドのCSS変数が継承されないため、実際の色値を素材に書く。
- 棒の基準線は0。折れ線は時間の間隔を位置に反映する。負数は0の上下へ描き、欠損値を0と解釈しない。構成比は非負で合計100%を確認する。
- 軸範囲から座標を計算する。棒の長さ・点・円弧と表示数値を照合し、丸め方を揃える。複数グラフの比較では軸の範囲も揃える。
- 目盛り・ラベル・凡例・単位の場所を先に確保する。長い項目名は横棒や改行で扱う。3D化・切り抜き・色だけの区別を避ける。
- `viewBox`・`title`・`desc` を付け、文字列をXMLエスケープする。SVG内部にJavaScriptや外部参照を入れない。
- 画像内のフォントはスライドのフォントとは別に描画される。配布先で字形を固定する必要がある場合は、作図ツール側で文字をアウトライン化するかPNGで書き出す。同梱例の軸ラベルは英数字と汎用フォントで構成している。
- スライドには通常の `![具体的な説明](...)` で挿入し、表示サイズで文字・余白・軸が読めるか確認する。生成できない場合に仮のグラフを実データとして提示しない。
