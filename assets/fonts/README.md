# M PLUS Rounded 1c

通常（400）・中太（500）・太字（700）を同梱しています。日本語を含む全グリフを維持し、元のTTFをWOFF形式に変換しています。字形の変更や文字の間引きは行っていません。

- 配布元：[Google Fonts / M PLUS Rounded 1c](https://github.com/google/fonts/tree/main/ofl/mplusrounded1c)
- ライセンス：[SIL Open Font License 1.1](OFL.txt)
- ライセンス原本：[MPLUS_FONTS](https://github.com/coz-m/MPLUS_FONTS/blob/master/OFL.txt)
- 取得日：2026-09-12

`aizome.css` の `@font-face` から読み込みます。HTMLを移動するときは `assets` フォルダも一緒に配置してください。コードブロックは可読性のため等幅フォントのままです。
